Exercício 1 — Contador

Fácil · @click, methods

Valor: {{ contador }}

Ver código

  return { contador: 0 };
},
methods: {
  incrementar() { this.contador++; },
  decrementar() { this.contador--; },
  zerar() { this.contador = 0; }
}

Exercício 2 — Olá, visitante

Fácil · v-model, v-if

Olá, {{ nome }}!

Ver código 
data() {
  return { nome: "" };
}

<input v-model="nome" placeholder="Digite seu nome">
<p v-if="nome">Olá, {{ nome }}!</p>
Atenção: v-if="nome" funciona porque string vazia é "falsy" em JS — não precisa escrever nome !== ''.

Exercício 3 — Nome completo

Fácil · v-model, computed

Nome completo: {{ nomeCompleto }}

Ver código 
data() {
  return { nome3: "", sobrenome3: "" };
},
computed: {
  nomeCompleto() {
    return (this.nome3 + " " + this.sobrenome3).trim();
  }
}

Exercício 6 — Adicionando frutas

Médio · v-model, @click, push

Digite uma fruta antes de adicionar!

  • {{ index + 1 }} - {{ fruta }}
Ver código 
data() {
  return { novaFruta: "", frutas6: ["Maçã", "Banana"], avisoFruta: false };
},
methods: {
  adicionarFruta() {
    if (this.novaFruta.trim() === "") {
      this.avisoFruta = true;
      return;
    }
    this.avisoFruta = false;
    this.frutas6.push(this.novaFruta.trim());
    this.novaFruta = "";
  }
}

Exercício 7 — Lista de alunos

Médio · v-for com objetos, :key
  • {{ aluno.nome }} — nota {{ aluno.nota }}

Média da turma: {{ mediaNotas }}

Ver código 
data() {
  return {
    alunos: [
      { id: 1, nome: "Ana",    nota: 8 },
      { id: 2, nome: "Bruno",  nota: 6 },
      { id: 3, nome: "Carla",  nota: 9 },
      { id: 4, nome: "Diego",  nota: 5 }
    ]
  };
},
computed: {
  mediaNotas() {
    const soma = this.alunos.reduce((acc, a) => acc + a.nota, 0);
    return (soma / this.alunos.length).toFixed(1);
  }
}

Exercício 8 — Quem passou?

Médio · computed
  • {{ aluno.nome }} — nota {{ aluno.nota }}

{{ aprovados }} de {{ alunos8.length }} alunos aprovados

Ver código 
computed: {
  aprovados() {
    return this.alunos8.filter(a => a.nota >= 7).length;
  }
}
Reatividade: se você mudar uma nota no data(), o aprovados recalcula sozinho — não precisa chamar nada.

Exercício 9 — Pense e responda

Médio · methods x computed, :key

a) Qual a diferença entre methods e computed?
methods é uma função que roda toda vez que é chamada (por exemplo, a cada clique). computed é um valor que o Vue calcula e guarda em cache, só recalculando quando algum dado usado dentro dele muda.

b) Para mostrar o total de itens de uma lista, você usaria qual dos dois? Por quê?
computed. Porque é um valor derivado dos dados (não uma ação), e o Vue evita recalcular à toa — só atualiza quando a lista realmente mudar.

c) Por que é melhor usar um id no :key em vez do índice?
Porque o índice muda quando um item é removido ou reordenado, fazendo o Vue confundir qual elemento é qual (pode misturar dados entre linhas). O id é único e fixo para cada item, então o Vue sempre sabe exatamente qual elemento atualizar.

Exercício 10 — Lista de Tarefas (To-Do List)

Desafio · tudo da aula

{{ restantes }} tarefa(s) restante(s)

Ver código 
data() {
  return { novaTarefa: "", tarefas: [] };
},
methods: {
  adicionar() {
    if (this.novaTarefa.trim() === "") return;
    this.tarefas.push({
      id: Date.now(),
      texto: this.novaTarefa.trim(),
      feita: false
    });
    this.novaTarefa = "";
  }
},
computed: {
  restantes() {
    return this.tarefas.filter(t => !t.feita).length;
  }
}
